# context-coach

Mod do Claude Code: faixa acima do prompt com barra de progresso do contexto em largura total (uma volta = 150k tokens, cor por volta), uso das 5h, aviso de reset e botões de atalho (handoff, compactar, ver uso). Os botões só escrevem o texto na caixa; você aperta Enter.

## Instalar

Digite no prompt de uma sessão do Claude Code:

```
/plugin install context-coach --marketplace DanielGodriNeto/context-coach
```

Depois confirme com `y` e escolha o escopo.
